nyxclaude — project file organization · terminal AI coding-agent harness (provider-agnostic fork of openclaude/Claude Code)

A React/Ink TUI that drives an LLM through a tool-augmented agent loop. No provider is hardcoded — configured at runtime via /provider into .nyxclaude-profile.json. Built with Bun into single-file .mjs bundles, run with Node ≥22.

used by harness at runtime build-time only (becomes dist/) dev tooling / scripts (not shipped) gitignored / generated

At runtime the harness only needs: bin/, dist/cli.mjs (+ dist/sdk.mjs for embeds), node_modules/ runtime deps, and the user's .nyxclaude-profile.json. Everything under src/ and scripts/ is build-time input, not loaded by the running app.

How to read this: the running harness = bin/nyxclaude → dist/cli.mjs (built from src/entrypoints/cli.tsx). The TUI (screens/REPL.tsx) drives the agent loop (query/) which calls the LLM through services/api/openaiShim.ts and executes capabilities from tools/. Provider config is read at startup from .nyxclaude-profile.json (created by the /provider command in commands/provider/). Everything in src/ is build input; only bin/ + dist/ + runtime deps ship.
