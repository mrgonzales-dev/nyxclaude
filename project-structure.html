src/ — Subdirectories
🚀entrypoints/
Top-level entry points: cli.tsx, mcp.ts, SDK export, init flow, sandbox types
⚙️query/
Query engine logic: step limits, auto-compact cooldown, goal continuation, stop hooks
🔧tools/
Tool implementations: AgentTool, BashTool, FileEditTool, GlobTool, GrepTool, WebFetch, TaskCreate, etc.
📋commands/
All slash-command implementations (add-dir, commit, compact, config, goal, issue, etc.)
🧠coordinator/
Multi-agent coordination: coordinator mode and worker-agent orchestration
📝tasks/
Task implementations: local agent, shell, remote agent, workflow, monitor-mcp, teammate
🌐services/
Core services: analytics, API client, autoFix, compact, context-collapse, summaries, limits, MCP, policy
🔌integrations/
Third-party integrations: aimlapi, anthropic proxies, gateways, discovery service, MCP registry
🖥️components/
React/Ink UI components: App, dialogs, inputs, agent progress lines, design-system
🎨ink/
Vendored custom Ink terminal-UI framework: rendering, DOM, events, focus, cursor
📱screens/
Top-level screens: Doctor diagnostics, REPL input dialog, model selection
⌨️keybindings/
Keybinding system: default bindings, parser, resolver, schema, user-config loading
✏️vim/
Vim-mode editing primitives: motions, operators, text objects, transitions
🪝hooks/
React hooks: file suggestions, notifications, tool permissions, arrow-key history, cancel, blink
🗂️context/
React context providers: mailbox, modal, notifications, overlay, stats, voice, repoMap
💬i18n/
Internationalization: locale loading, command descriptions, language packs
📡remote/
Remote session management: permission bridge, SDK message adapter, WebSocket sessions
🖥️server/
Server backend: direct-connect sessions, headless connect, lockfile, banner, session manager
🔒ssh/
SSH session creation and management
🔄upstreamproxy/
Upstream proxy relay for forwarding requests
🏗️bootstrap/
Early startup state: session ID, project root, channels — shared across the app
📦cli/
Non-interactive/headless CLI plumbing: background registry, heartbeat, exit handling
🦀daemon/
Background daemon entrypoint and worker registry
🏃environment-runner/
Standalone runner entrypoint for executing environments
🤖self-hosted-runner/
Self-hosted runner entrypoint
⛓️grpc/
gRPC server implementation
📜proto/

🔀migrations/
Settings/config migrations between versions
🗃️state/
Global app state store, selectors, plugin-commands store, change handling
📐types/
Shared TypeScript type definitions: command, message, hooks, ids, logs, permissions, plugin
📋schemas/
Shared schema definitions (hooks)

Built-in and bundled plugin system
🎯skills/

Loading of custom output style directories
🔔proactive/
Proactive behavior module
💼jobs/

🦮assistant/
Assistant session discovery, history serialization, session chooser UI

Pixel-art companion feature: sprites, effects, notifications, shot-clock hook
🎤voice/
Voice-mode enablement flag
🏷️constants/
Static constants: API limits, brand, error IDs, figures, messages, file paths
🛠️utils/
General utilities: abort, advisor, ANSI, git, cwd, settings, auth, model providers, fast mode, etc.
⚛️native-ts/
Native TS reimplementations of native deps (color-diff, file-index, yoga-layout)
🧪test/
Test fixtures, mock helpers, safety-level test helpers, shared mutation lock
🔬__tests__/
Cross-cutting integration tests: bugfixes, doctor warnings, process title, security hardening
src/ — Top-level Files (used by main harness)
main.tsx — Primary CLI entrypoint; Commander setup, startup profiling, launches REPL
QueryEngine.ts — Core conversation engine: message handling, auto-compact, tool-use, SDK emission
query.ts — Query orchestration helpers: SDK message types, permission modes, usage accumulation
Tool.ts — Core Tool interface, input schema types, permission context
tools.ts — Aggregates and exports all Tool implementations, applies deny rules
Task.ts — Task interface and TaskType / TaskStatus enums
tasks.ts — Aggregates all available Task implementations
commands.ts — Central registry importing and exporting all slash-command implementations
context.ts — Builds system context (CLAUDE.md, git branch, repo map) injected into prompts
replLauncher.tsx — Launches REPL by mounting App + REPL into the Ink root
ink.ts — Thin wrapper around custom Ink renderer, injects ThemeProvider
setup.ts — First-run setup: trust dialog, API key normalization, MCP approvals, GrowthBook init
cost-tracker.ts — Tracks API usage/costs per model, cache metrics, routing summaries
costHook.ts — React hook that prints total cost and saves session costs on exit
history.ts — Persists and reads conversation history entries and pasted content
dialogLaunchers.tsx — Dynamic import launchers for one-off dialog components
interactiveHelpers.tsx — Shared helpers: renderAndRun, showSetupDialog, keybinding setup, stats wiring
projectOnboardingState.ts — Tracks and persists whether project onboarding is complete
projectOnboardingSteps.ts — Defines onboarding steps and completion checks
